# Prime-explorer
This projects groups consecutive prime numbers under a chosen limit together by their difference then stores them in a json file
# 
Method:

The code will first find the different individual primes from 0 to the limit provided. The next part of the code then involves finding the difference between consecutive pairs. Once this is found, then the two primes are put inside of their respective groupings within a dictionary before pushed onto a json file once all the consecutive primes have been filtered through.
